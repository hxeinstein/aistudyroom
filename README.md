# 🌳 숲속 독서실 (AI Study Room)

시험기간용 3D 온라인 독서실입니다. 자리에 앉아 **무엇을 공부할지 고르고 ▶ 시작**을 누르면 시간이 자동으로 기록되고,
**🌙 오늘 공부끝**을 누르면 그날의 **스터디플래너가 사진(PNG)으로 저장**됩니다.

- 누구나 링크로 바로 입장 (로그인 없음)
- 기록은 **각자 기기(브라우저)에만 저장** — 휴대폰/태블릿에서 사용
- 배경 소리: 🌫️ 백색소음 · 🌧️ 빗소리 (오른쪽 위 버튼으로 전환)
- 동물의숲처럼 아기자기한 숲속 분위기, 실제 시간에 따라 낮 · 노을 · 밤으로 바뀜

## 화면 조작
- 바닥을 누르면 그곳으로 이동, 책상을 누르면 앉기
- **화면을 끌면** 캐릭터를 중심으로 360° 돌아보기 (가로: 빙글, 세로: 높낮이)
- **두 손가락 벌리기/모으기**(PC는 마우스 휠) 또는 오른쪽 위 **＋ / －**로 확대·축소, **⟲**로 처음 시점
- 학생은 로그인이 없어요: 같은 기기(같은 브라우저)면 닉네임·캐릭터·과목·기록이 계속 유지돼요

## 사용 흐름
1. 닉네임과 동물 캐릭터 20종 중 하나를 고르고 입장 (동물마다 덩치·걸음 속도가 달라요 — 생쥐는 방석을 쌓고 앉고, 코끼리는 엉덩이가 의자 밖으로, 나무늘보는 느릿느릿)
2. 빈 책상을 누르거나 **🪑 빈자리 앉기** → 캐릭터가 걸어가서 앉음
3. 처음 한 번은 **📚 내 과목**에서 우리 학교 과목을 직접 추가 (이 기기에 계속 저장, ⚙️ 설정에서 추가·빼기)
   → 과목 + 할 일 + 세부 내용 입력 → **▶ 공부 시작** (스탠드가 켜지고 책상 시점으로 확대)
4. **☕ 잠깐 휴식**(휴식 시간은 기록에서 제외) / **⏹ 이 공부 끝** → "다 끝냈어요"를 누르면 할 일 체크
5. **🌙 오늘 공부끝** → 한 줄 회고 입력 → 📸 플래너 사진 저장

## 스터디플래너 구성 (자동 완성)
| 영역 | 내용 |
|---|---|
| 헤더 | 날짜, 캐릭터, D-day(⚙️ 설정에서 시험 이름·날짜 입력), TOTAL TIME |
| SUBJECTS & HIGH-LIGHTS | 오늘 공부한 과목 색 + 과목별 시간 |
| TO-DO LIST | 공부 시작할 때 적은 할 일과 세부 내용, 완료하면 체크와 취소선 |
| TIME TABLE (10 Min Grid) | 06시~다음날 05시, 10분 칸에 과목 색이 자동으로 칠해짐 |
| TODAY'S NOTE | 오늘 공부끝에서 쓴 한 줄 회고 |

- 하루는 **새벽 6시**에 바뀝니다 (밤샘 공부도 같은 날 플래너에 기록).
- 플래너 화면의 ◀ ▶ 버튼으로 지난 날짜의 플래너도 다시 볼 수 있습니다.
- 휴대폰에서는 공유 창의 "이미지 저장"을 누르거나, 미리보기 이미지를 길게 눌러 사진첩에 저장합니다.

## 🐾 질문 챗봇 (교무실 질문 코너)
교무실 입구 앞 **질문 코너**에 챗봇들이 있어요 — 🐶 **뭉치 박사**(과학), 🦁 **도덕후**(도덕). 누르면 그 앞까지 걸어가서 대화창이 열려요.
공부 중에는 그 과목이 연결된 교과일 때만 **🐾 질문** 버튼이 보이고, 맞는 챗봇이 바로 열려요.
- 챗봇으로 안 풀리면 대화창의 **👩‍🏫 선생님께 물어보기** → 선생님 고르기 → 방금 한 질문이 입력칸에 들어간 교무실 대화가 열리고, **이때 선생님께 알림**이 가요.
- 학생이 선생님 자리를 바로 누르면 "챗봇에게 먼저 물어보세요"라고 한 번 권해요.
- 선생님이 모두 문을 닫아도(시험 출제 중) 교무실에는 들어갈 수 있어요. 챗봇은 언제나 질문을 받아요.
- 말투: 뭉치 박사는 "저항~!"·"과하하학", 도덕후는 "덕스럽다~!"·"후후후" (`Code.gs`의 `BOT_PERSONAS`)
- 새 챗봇: 캐릭터 그림과 이름을 알려 주면 3D로 만들어 `js/config.js`의 `BOTS`와 `Code.gs`의 `BOT_PERSONAS`에 추가해요. 시트 `과목` 탭 **H칸(챗봇)**에 그 이름을 적으면 그 교과를 맡아요.
- 공통: 정답 대신 단계별 힌트, 교과서 쪽수 안내(노란색 강조), 문제 사진 올리기, 대화는 화면에만 있고 새로고침하면 사라짐
- 독서실에서 온 질문은 '기록' 시트에 남기지 않음 (`STUDYROOM_SAVE_LOG`) · 사용량 제한: 기기당 약 6시간에 30회, 하루 전체 1,500회

### 연결 방법 (선생님이 한 번만)
1. 기존 힌트 코치 Apps Script 프로젝트를 열고, `Code.gs` 내용을 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)로 바꿉니다.
   (기존 기능은 그대로이고 `doPost`, 사용량 제한, 마스코트 말투만 추가됨. 프롬프트·교과서 시트는 그대로 사용)
2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 액세스 권한은 **모든 사용자**.
3. 나온 **웹 앱 URL**(`…/exec`)을 [`js/config.js`](js/config.js)의 `CHATBOT_URL`에 붙여 넣습니다.
4. 수업 코드(`ACCESS_CODE`)를 설정해 두었다면 학생은 처음 한 번 코드를 입력합니다.
5. 편집기에서 `setupSubjects` 함수를 한 번 실행하면 `과목` 탭이 생기고, 지금의 역학과 에너지가 첫 줄로 등록돼요.

### 교과 추가하기 (`과목` 탭, 다시 배포할 필요 없음)
| A 사용 | B 교과 이름 | C 연결 낱말 | D 교과서 탭 이름 | E 프롬프트 | F 첫 인사 | G 수업 코드 | H 챗봇 |
|---|---|---|---|---|---|---|---|
| ☑ | 역학과 에너지 | 과학, 물리, 역학 | 교과서 | (비우면 `프롬프트` 탭 A1) | (비우면 기본 인사) | NY2026 | 뭉치 박사 |
| ☑ | 생활과 윤리 | 도덕, 윤리 | (비움: 교과서 없이) | 너는 도덕 힌트 코치야… | 어떤 도덕 고민이 있니? | | 도덕후 |

1. 교과서 탭을 새로 만들고 기존 `교과서` 탭과 같은 열(**쪽, 대단원, 소단원, 내용**)로 채웁니다.
2. `과목` 탭에 한 줄을 추가하고 **사용**에 체크합니다. **체크 + D칸의 탭이 실제로 있을 때만** 독서실에 나타나요.
3. C칸(연결 낱말): 학생이 직접 만든 과목 이름에 이 낱말이 들어가면 연결돼요. 예) `과학, 물리, 역학` → '물리학Ⅰ', '통합과학' 공부 중에 🐾 질문 버튼이 보이고 이 교과가 먼저 선택됨.
4. 프롬프트에 "첫 인사가 이미 나와 있어"라는 문장이 있다면 F칸 첫 인사와 같은 문장으로 맞춰 주세요.
5. **D칸을 비우면 교과서 없는 교과**: 쪽수 안내 없이 개념으로만 힌트 (출판사가 다른 학생도 OK)
6. **G칸 수업 코드**: 적으면 그 코드를 아는 학생만 사용(우리 학교 교과서 교과 추천), 비우면 누구나. 시험 기간마다 바꿔도 돼요.
   이미 `과목` 탭이 있다면 `setupSubjects`를 한 번 더 실행하면 머리글(G칸)만 최신으로 바뀝니다.

## 🏫 교무실 (선생님과 1:1 대화)
공부방 오른쪽의 **교무실** 건물(또는 데크 끝 표지판)을 누르면 들어가요. 선생님 자리 10개가 있어요.
- 접속한 선생님이 있으면 문이 열리고 자리에 캐릭터가 앉아 있어요(🟢 상담 가능). 아무도 없으면 문이 닫히고 **📝 시험 출제 중** 팻말이 붙어요. 그래도 들어가서 메시지를 남길 수 있어요.
- 학생 ↔ 선생님, 선생님 ↔ 선생님만 대화할 수 있어요 (학생끼리는 서버에서 막음).
- 대화는 시트에 저장하지 않아요. 어느 한쪽이 **끝내기**를 누르면 바로 지워지고, 늦어도 6시간 뒤 자동 삭제.
- 학생은 ⌄ 로 대화창을 내려 두고 공부하면서 답장을 기다릴 수 있어요.
- **선생님이 독서실을 켜 두지 않아도 돼요**: 등록할 때 이메일을 적으면, 교무실에 없을 때 질문이 오면 메일로 알려 드려요(내용은 안 넣음, 같은 대화 10분에 한 번). 메일의 링크를 누르면 바로 교무실로 들어가요.
- 선생님은 학생을 **차단**할 수 있어요 (`차단` 탭에 기기 번호만 남음).
- 선생님은 **🔒 문 닫기**로 질문을 받지 않을 수 있어요. 학생에게는 '📝 시험 출제 중'으로 보이고 새 질문을 열 수 없어요(하던 대화는 계속). 모든 선생님이 문을 닫으면 교무실에 들어갈 수 없어요. 다시 받으려면 **🔓 문 열기** (`교사` 탭 I칸에도 표시).

### 교무실 설치 (선생님이 한 번만)
1. 같은 Apps Script 프로젝트에 파일 추가(+) → 스크립트 → 이름 `Office` → [`apps-script/Office.gs`](apps-script/Office.gs) 내용 붙여 넣기. `Code.gs`도 최신으로 바꾸기.
2. 편집기에서 `setupOffice` 실행 → `교사`·`차단` 탭이 생기고 초대코드 3개가 만들어져요 (메일 권한 승인).
3. **배포 → 배포 관리 → 연필 → 새 버전 → 배포** (주소는 그대로).
4. 선생님들께 초대코드를 한 명에 하나씩 알려 주세요. 독서실 ⚙️ 설정(또는 교무실 안) → **👩‍🏫 선생님 로그인 → 처음 등록**에서 초대코드·닉네임·비밀번호·이메일과 **선생님 캐릭터**(동물·옷 색·안경, 교사증 목걸이) 선택.
   다음부터는 **초대코드 + 닉네임 + 비밀번호**로 로그인하고, 한 번 로그인한 기기는 로그아웃할 때까지 계속 로그인돼 있어요. 로그인하면 그 기기의 학생 캐릭터 대신 선생님 캐릭터로 바뀌어요.
5. 초대코드가 더 필요하면 시트 메뉴 **🐾 독서실 → 교사 초대코드 만들기**. 권한을 빼려면 `교사` 탭의 '사용' 체크 해제.

## 실행
정적 파일만으로 동작합니다 (빌드 없음).
```bash
python3 -m http.server 8000   # → http://localhost:8000
```
GitHub Pages로 배포하려면 저장소 Settings → Pages에서 이 브랜치의 루트(/)를 선택하면 됩니다.

## 파일 구조
```
index.html        화면 뼈대 (HUD, 행동 바, 공부 패널, 모달)
css/style.css     따뜻한 크림·나무 톤 UI
js/app.js         화면 흐름 (입장 → 앉기 → 공부 → 종료 → 플래너)
js/world.js       Three.js 3D 숲속 독서실, 좌석, 뭉치 박사, 길찾기
js/animals.js     동물 캐릭터 20종 (덩치·속도·생김새 특징)
js/store.js       기록 저장 (localStorage), 세션/할 일/통계
js/planner.js     스터디플래너 이미지 렌더링 + 사진 저장
js/sound.js       백색소음 · 빗소리 (직접 합성)
js/chat.js        뭉치 박사 질문 챗봇 창 (Apps Script 호출)
js/office.js      교무실 대화·선생님 로그인·받은 대화함
js/config.js      챗봇 주소 · 마스코트 이름 설정
apps-script/      Code.gs(힌트 코치 + 독서실 입구) · Office.gs(교무실) · Index.html(기존 웹앱)
assets/            챗봇 그림 (mascot.png 뭉치 박사, dodeokhu.png 도덕후)
vendor/           three.js r160 (MIT)
```
3D 공간과 캐릭터는 그림 파일 없이 코드로 직접 만들었습니다.
