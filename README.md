# 🌳 숲속 독서실 (AI Study Room)

시험기간용 3D 온라인 독서실입니다. 자리에 앉아 **무엇을 공부할지 고르고 ▶ 시작**을 누르면 시간이 자동으로 기록되고,
**🌙 오늘 공부끝**을 누르면 그날의 **스터디플래너가 사진(PNG)으로 저장**됩니다.

- 누구나 링크로 바로 입장 (로그인 없음)
- 기록은 **각자 기기(브라우저)에만 저장** — 휴대폰/태블릿에서 사용
- 배경 소리: 🌫️ 백색소음 · 🌧️ 빗소리 (오른쪽 위 버튼으로 전환)
- 동물의숲처럼 아기자기한 숲속 분위기, 실제 시간에 따라 낮 · 노을 · 밤으로 바뀜

## 사용 흐름
1. 닉네임과 동물 캐릭터(곰·토끼·고양이·여우·판다·개구리)를 고르고 입장
2. 빈 책상을 누르거나 **🪑 빈자리 앉기** → 캐릭터가 걸어가서 앉음
3. 과목 + 할 일 + 세부 내용 입력 → **▶ 공부 시작** (스탠드가 켜지고 책상 시점으로 확대)
4. **☕ 잠깐 휴식**(휴식 시간은 기록에서 제외) / **⏹ 이 공부 끝** → "다 끝냈어요"를 누르면 할 일 체크
5. **🌙 오늘 공부끝** → 한 줄 회고 입력 → 📸 플래너 사진 저장

## 스터디플래너 구성 (자동 완성)
| 영역 | 내용 |
|---|---|
| 헤더 | 날짜, 캐릭터, D-day(⚙️ 설정에서 시험 이름·날짜 입력), TOTAL TIME |
| SUBJECTS & HIGH-LIGHTS | 오늘 공부한 과목 색 + 과목별 시간 |
| TO-DO LIST | 공부 시작할 때 적은 할 일과 세부 내용, 완료하면 체크와 취소선 |
| TIME TABLE (10 Min Grid) | 06시~다음날 05시, 10분 칸에 과목 색이 자동으로 칠해짐 |
| TODAY'S NOTE | 오늘 공부끝에서 쓴 한 줄 회고 |

- 하루는 **새벽 6시**에 바뀝니다 (밤샘 공부도 같은 날 플래너에 기록).
- 플래너 화면의 ◀ ▶ 버튼으로 지난 날짜의 플래너도 다시 볼 수 있습니다.
- 휴대폰에서는 공유 창의 "이미지 저장"을 누르거나, 미리보기 이미지를 길게 눌러 사진첩에 저장합니다.

## 🐾 과학 질문 (뭉치 박사)
입구 러그 옆의 **뭉치 박사**를 누르거나 하단 **🐾 과학 질문** 버튼(공부 중에는 **🐾 질문**)을 누르면 채팅창이 열립니다.
선생님이 만든 **역학과 에너지 힌트 코치**(Apps Script + Gemini)를 그대로 불러 씁니다.
- 정답 대신 단계별 힌트, 교과서 쪽수 안내(노란색 강조), 문제 사진 올리기
- 공부 타이머는 그대로 흐름 · 대화는 화면에만 있고 새로고침하면 사라짐
- 독서실에서 온 질문은 '기록' 시트에 남기지 않음 (`STUDYROOM_SAVE_LOG`)
- 사용량 제한: 기기당 약 6시간에 30회, 하루 전체 1,500회 (`DEVICE_LIMIT`, `DAILY_LIMIT`)

### 연결 방법 (선생님이 한 번만)
1. 기존 힌트 코치 Apps Script 프로젝트를 열고, `Code.gs` 내용을 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)로 바꿉니다.
   (기존 기능은 그대로이고 `doPost`, 사용량 제한, 마스코트 말투만 추가됨. 프롬프트·교과서 시트는 그대로 사용)
2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 액세스 권한은 **모든 사용자**.
3. 나온 **웹 앱 URL**(`…/exec`)을 [`js/config.js`](js/config.js)의 `CHATBOT_URL`에 붙여 넣습니다.
4. 수업 코드(`ACCESS_CODE`)를 설정해 두었다면 학생은 처음 한 번 코드를 입력합니다.

## 실행
정적 파일만으로 동작합니다 (빌드 없음).
```bash
python3 -m http.server 8000   # → http://localhost:8000
```
GitHub Pages로 배포하려면 저장소 Settings → Pages에서 이 브랜치의 루트(/)를 선택하면 됩니다.

## 파일 구조
```
index.html        화면 뼈대 (HUD, 행동 바, 공부 패널, 모달)
css/style.css     따뜻한 크림·나무 톤 UI
js/app.js         화면 흐름 (입장 → 앉기 → 공부 → 종료 → 플래너)
js/world.js       Three.js 3D 숲속 독서실, 동물 캐릭터, 길찾기
js/store.js       기록 저장 (localStorage), 세션/할 일/통계
js/planner.js     스터디플래너 이미지 렌더링 + 사진 저장
js/sound.js       백색소음 · 빗소리 (직접 합성)
js/chat.js        과학 질문 챗봇 창 (Apps Script 호출)
js/config.js      챗봇 주소 · 마스코트 이름 설정
apps-script/      힌트 코치 Apps Script (Code.gs에 독서실 연결 추가)
assets/mascot.png 뭉치 박사 그림
vendor/           three.js r160 (MIT)
```
3D 공간과 캐릭터는 그림 파일 없이 코드로 직접 만들었습니다.
