# 🌳 숲속 독서실 (AI Study Room)

시험기간용 3D 온라인 독서실입니다. 자리에 앉아 **무엇을 공부할지 고르고 ▶ 시작**을 누르면 시간이 자동으로 기록되고,
**🌙 오늘 공부끝**을 누르면 그날의 **스터디플래너가 사진(PNG)으로 저장**됩니다.

- 누구나 링크로 바로 입장 (로그인 없음)
- 기록은 **각자 기기(브라우저)에만 저장** — 휴대폰/태블릿에서 사용
- 배경 소리: 🌫️ 백색소음 · 🌧️ 빗소리 (오른쪽 위 버튼으로 전환)
- 동물의숲처럼 아기자기한 숲속 분위기, 실제 시간에 따라 낮 · 노을 · 밤으로 바뀜

## 화면 조작
- 바닥을 누르면 그곳으로 이동, 책상을 누르면 앉기
- 휴대폰·태블릿은 **왼쪽 아래 조이스틱**으로 걷기 (조금 밀면 천천히, 끝까지 밀면 빠르게). PC는 WASD·방향키
- **화면을 끌면** 캐릭터를 중심으로 360° 돌아보기 (가로: 빙글, 세로: 높낮이)
- **두 손가락 벌리기/모으기**(PC는 마우스 휠) 또는 오른쪽 위 **＋ / －**로 확대·축소, **⟲**로 처음 시점
- **선생님(구경 시점)은 지도 앱처럼**: 끌기 = 화면 옮기기, 오른쪽 버튼 끌기(또는 Ctrl+끌기)·두 손가락 비틀기 = 돌리기, 휠·두 손가락 벌리기 = 확대·축소, 클릭 = 그곳으로 이동, 학생 클릭 = 말 걸기
- 학생은 로그인이 없어요: 같은 기기(같은 브라우저)면 닉네임·캐릭터·과목·기록이 계속 유지돼요. 공용 태블릿은 ⚙️ 설정 → **🚪 이 기기에서 나가기**로 그 기기의 기록을 지우고 처음 화면으로

## 사용 흐름
1. 닉네임과 동물 캐릭터 20종 중 하나를 고르고 입장 (동물마다 덩치·걸음 속도가 달라요 — 생쥐는 방석을 쌓고 앉고, 코끼리는 엉덩이가 의자 밖으로, 나무늘보는 느릿느릿)
2. 빈 책상을 누르거나 **🪑 빈자리 앉기** → 캐릭터가 걸어가서 앉음
3. 처음 한 번은 **📚 내 과목**에서 우리 학교 과목을 직접 추가 (이 기기에 계속 저장, ⚙️ 설정에서 추가·빼기)
   → 과목 + 할 일 + 세부 내용 입력 → **▶ 공부 시작** (스탠드가 켜지고 책상 시점으로 확대)
4. **☕ 잠깐 휴식**(휴식 시간은 기록에서 제외) / **⏹ 이 공부 끝** → "다 끝냈어요"를 누르면 할 일 체크
5. **🌙 오늘 공부끝** → 한 줄 회고 입력 → 📸 플래너 사진 저장

## 스터디플래너 구성 (자동 완성)
| 영역 | 내용 |
|---|---|
| 헤더 | 날짜, 캐릭터, D-day(⚙️ 설정에서 시험 이름·날짜 입력), TOTAL TIME |
| SUBJECTS & HIGH-LIGHTS | 오늘 공부한 과목 색 + 과목별 시간 |
| TO-DO LIST | 공부 시작할 때 적은 할 일과 세부 내용, 완료하면 체크와 취소선 |
| TIME TABLE (10 Min Grid) | 06시~다음날 05시, 10분 칸에 과목 색이 자동으로 칠해짐 |
| TODAY'S NOTE | 오늘 공부끝에서 쓴 한 줄 회고 |

- 하루는 **새벽 6시**에 바뀝니다 (밤샘 공부도 같은 날 플래너에 기록).
- 플래너 화면의 ◀ ▶ 버튼으로 지난 날짜의 플래너도 다시 볼 수 있습니다.
- 휴대폰에서는 공유 창의 "이미지 저장"을 누르거나, 미리보기 이미지를 길게 눌러 사진첩에 저장합니다.

## 🐾 질문 챗봇 (교무실 질문 코너)
교무실 입구 앞 **질문 코너**에 챗봇들이 있어요 — 🐶 **뭉치 박사**(과학), 🦁 **도덕후**(도덕). 누르면 그 앞까지 걸어가서 대화창이 열려요.
공부 중에는 그 과목이 연결된 교과일 때만 **🐾 질문** 버튼이 보이고, 맞는 챗봇이 바로 열려요.
- 챗봇으로 안 풀리면 대화창의 **👩‍🏫 선생님께 물어보기** → 선생님 고르기 → 방금 한 질문이 입력칸에 들어간 교무실 대화가 열리고, **이때 선생님께 알림**이 가요.
- 학생이 선생님 자리를 바로 누르면 "챗봇에게 먼저 물어보세요"라고 한 번 권해요.
- 선생님이 모두 문을 닫아도(시험 출제 중) 교무실에는 들어갈 수 있어요. 챗봇은 언제나 질문을 받아요.
- 말투: 뭉치 박사는 "저항~!"·"과하하학", 도덕후는 "덕스럽다~!"·"후후후" (`Code.gs`의 `BOT_PERSONAS`)
- 새 챗봇: 캐릭터 그림과 이름을 알려 주면 3D로 만들어 `js/config.js`의 `BOTS`와 `Code.gs`의 `BOT_PERSONAS`에 추가해요. 시트 `과목` 탭 **H칸(챗봇)**에 그 이름을 적으면 그 교과를 맡아요.
- 공통: 정답 대신 단계별 힌트, 교과서 쪽수 안내(노란색 강조), 문제 사진 올리기, 대화는 화면에만 있고 새로고침하면 사라짐
- 독서실에서 온 질문은 '기록' 시트에 남기지 않음 (`STUDYROOM_SAVE_LOG`) · 사용량 제한: 기기당 약 6시간에 30회, 하루 전체 1,500회

### 연결 방법 (선생님이 한 번만)
1. 기존 힌트 코치 Apps Script 프로젝트를 열고, `Code.gs` 내용을 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs)로 바꿉니다.
   (기존 기능은 그대로이고 `doPost`, 사용량 제한, 마스코트 말투만 추가됨. 프롬프트·교과서 시트는 그대로 사용)
2. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**. 액세스 권한은 **모든 사용자**.
3. 나온 **웹 앱 URL**(`…/exec`)을 [`js/config.js`](js/config.js)의 `CHATBOT_URL`에 붙여 넣습니다.
4. 수업 코드(`ACCESS_CODE`)를 설정해 두었다면 학생은 처음 한 번 코드를 입력합니다.
5. 편집기에서 `setupSubjects` 함수를 한 번 실행하면 `과목` 탭이 생기고, 지금의 역학과 에너지가 첫 줄로 등록돼요.

### 교과 추가하기 (`과목` 탭, 다시 배포할 필요 없음)
| A 사용 | B 교과 이름 | C 연결 낱말 | D 교과서 탭 이름 | E 프롬프트 | F 첫 인사 | G 수업 코드 | H 챗봇 | I 담당 선생님 |
|---|---|---|---|---|---|---|---|---|
| ☑ | 역학과 에너지 | 과학, 물리, 역학 | 교과서 | (비우면 `프롬프트` 탭 A1) | (비우면 기본 인사) | NY2026 | 뭉치 박사 | 김과학 |
| ☑ | 생활과 윤리 | 도덕, 윤리 | (비움: 교과서 없이) | 너는 도덕 힌트 코치야… | 어떤 도덕 고민이 있니? | | 도덕후 | |

1. 교과서 탭을 새로 만들고 기존 `교과서` 탭과 같은 열(**쪽, 대단원, 소단원, 내용**)로 채웁니다.
2. `과목` 탭에 한 줄을 추가하고 **사용**에 체크합니다. **체크 + D칸의 탭이 실제로 있을 때만** 독서실에 나타나요.
3. C칸(연결 낱말): 학생이 직접 만든 과목 이름에 이 낱말이 들어가면 연결돼요. 예) `과학, 물리, 역학` → '물리학Ⅰ', '통합과학' 공부 중에 🐾 질문 버튼이 보이고 이 교과가 먼저 선택됨.
4. 프롬프트에 "첫 인사가 이미 나와 있어"라는 문장이 있다면 F칸 첫 인사와 같은 문장으로 맞춰 주세요.
5. **D칸을 비우면 교과서 없는 교과**: 쪽수 안내 없이 개념으로만 힌트 (출판사가 다른 학생도 OK)
6. **G칸 수업 코드**: 적으면 누구나 질문은 되고, 챗봇 대화창의 [🔑 수업 코드 넣기]로 코드를 넣은 학생만 **교과서 쪽수까지** 안내받아요(우리 학교 교과서 교과 추천). 비우면 누구나 교과서 연동. 시험 기간마다 바꿔도 돼요.
   이미 `과목` 탭이 있다면 `setupSubjects`를 한 번 더 실행하면 머리글(G칸)만 최신으로 바뀝니다.

## 👥 같이 공부하기 (실시간)
- **진짜 친구들이 실시간으로 보여요**: 걸어 들어오고, 자리에 앉고, 공부를 시작하면 스탠드가 켜지고 "📚 물리학Ⅰ 열공 중 · 42분"이 떠요. 앱을 닫으면 바로 사라져요.
- 자리는 **먼저 앉은 친구만** 차지해요. 교무실에 간 친구는 교무실에서 보여요.
- 친구를 누르면 **👏💪🔥😊🍀⭐ 응원**을 보낼 수 있어요 (머리 위에 떠오름). 학생끼리 채팅은 안 돼요.
- 선생님(구경 시점)은 학생을 눌러 **말을 걸 수 있어요**.
- 진짜 친구가 3명 이상이면 분위기용 친구들은 쉬어요.
- **Firebase 실시간 데이터베이스**(프로젝트 `aistudyroom`, 싱가포르, 무료 요금제·동시 접속 100명)를 써요. 나누는 건 닉네임·동물·위치·자리·공부 과목·시간뿐이고, 익명 로그인이라 개인정보는 없어요.
  설정 값은 `js/config.js`의 `FIREBASE`, 보안 규칙은 아래 [Firebase 보안 규칙](#firebase-보안-규칙).
- 연결이 안 되면(인터넷·차단) 혼자 공부 모드로 그대로 쓸 수 있어요.

## 📌 응원 게시판 · 📮 건의함 (공부방 안쪽 벽, 책장 사이)
- **응원 게시판**: 친구에게 응원 포스트잇(받는 친구·색 선택, 80자)을 붙여요. 30일 동안 보이고, 3D 게시판에도 최근 8장이 붙어 있어요.
  욕설은 막히고, 1시간에 5장까지. 두 사람이 신고하면 바로 숨겨져요. 쓴 사람과 관리자만 뗄 수 있어요. (시트 `게시판` 탭)
- **건의함**: 누구나 "있었으면 좋겠는 것, 고쳤으면 좋겠는 것"을 넣어요. **관리자('교사' 탭 L칸 체크)**만
  독서실에서 [📥 받은 대화 → 📮 건의함 보기]로 모아 보고 확인함/반영함/보류로 표시해요. 새 건의가 오면 관리자 메일로 알림(1시간에 한 번). (시트 `건의함` 탭)
  - 시트 G칸 **공개**에 체크하면 그 건의와 H칸 **선생님 댓글**이 학생들 건의함 화면(📢 친구들의 건의와 선생님 답)에 보여요. 관리자 화면에서도 댓글·공개를 바로 저장할 수 있어요.
  - 건의한 학생은 같은 기기로 들어오면 댓글이 달리거나 반영됐을 때 알림이 떠요 (📬 내 건의에서 확인).
  관리자는 시트 메뉴 [🐾 독서실 → 관리자 지정하기]로 정하거나 '교사' 탭 L칸을 체크해요. **코드 안에는 개인정보·초대코드·학교 코드·위치를 적지 않아요 (모두 시트에만).**

## 📚 교과서 넣기 (관리자)

`book.html` (사이트 주소 뒤에 `/book.html`) — 관리자 선생님이 열어요. 로그인이 안 되어 있으면 이 페이지에서 바로 로그인해요.
교과서 PDF를 고르면 **브라우저 안에서만** 쪽마다 글자를 뽑아(pdf.js), 몇 쪽씩 나눠 시트에 새 탭(쪽 | 대단원 | 소단원 | 내용)으로 넣고, 원하면 '과목' 탭에도 등록해요.
PDF 장 번호와 인쇄된 쪽 번호의 차이를 맞추고, 목차를 "시작 쪽 | 대단원 | 소단원" 줄로 적으면 단원까지 채워져요. 스캔본(사진) PDF는 글자를 뽑을 수 없어요.

## 🏫 여러 학교가 같이 쓰기 (학교 코드)
- 학생은 처음 들어올 때 **학교 코드**를 넣거나, **`…/aistudyroom/?school=코드`** 링크로 들어와요. 기기마다 기억해요 (🚪 나가기 하면 지워짐).
- 학교마다 따로: 실시간 공부방·자리·응원, 접속 중·순위, 응원 게시판·건의함·공지, 공부·질문 통계, 교무실 선생님, 챗봇 교과.
- 챗봇 교과: 시트 `과목` 탭 **J칸(학교 코드)** — 비우면 기본 학교(`학교` 탭 맨 위 학교)만, 코드를 적으면 그 학교만, `*`면 모든 학교. 학교 코드는 사이트 코드에 적혀 있지 않아요 (바꿀 때는 시트 메뉴 [🐾 독서실 → 학교 코드 바꾸기]).
- 관리자(⚙️ 설정 → 🏫 학교 관리): 학교 만들기(코드 자동/직접), 링크 복사, 끄기, **이 학교로 보기**(그 학교 공부방·요약·공지·초대코드 관리). 그 학교 선생님 초대코드는 그 학교로 바꾼 뒤 관리자 메뉴 → 선생님에서 만들어요 (`교사` 탭 K칸에 학교).
- 선생님은 로그인하면 자기 학교로 자동으로 맞춰져요. 예전부터 쓰던 기기와 학교 칸이 빈 기록은 기본 학교예요. 시트 `학교` 탭에 학교 목록이 있어요.

## 🪶 가볍게 그리기 (`js/bake.js`)
- 움직이지 않는 장식(나무·꽃·자갈·기차 침목·책장·책상)과 놀이기구 뼈대는 같은 색끼리 합쳐서 한 번에 그려요. 그리기 호출: 공부방 약 700 → 240, 쉼터 약 450 → 150.

## 🏫 교무실 (챗봇 선생님) · 👩‍🏫 진짜 선생님
- **교무실에는 챗봇 선생님 책상만** 있어요 (뭉치 박사 · 과학, 도덕후 · 도덕 …). 과목에 맞는 책상을 눌러 질문해요. 교무실은 언제나 열려 있어요.
- **진짜 선생님은 캐릭터가 없어요.** 챗봇 대화창의 **👩‍🏫 선생님 부르기**를 누르면 선생님과의 대화창이 열리고 이때 알림이 가요.
  - `과목` 탭 **I칸(담당 선생님)**에 선생님 닉네임을 적으면 그 과목은 담당 선생님께 바로 연결 (시험 출제 중이면 다른 선생님 목록).
- 선생님은 로그인하면 **캐릭터 없이 구경하는 시점**이 돼요. 공부 중인 학생을 누르면 **말을 걸 수 있어요** (학생에게 "선생님이 말을 걸었어요" 알림).
- 대화는 시트에 저장하지 않아요. 어느 한쪽이 **끝내기**를 누르면 바로 지워지고, 늦어도 마지막 메시지에서 12시간 뒤 자동 삭제.
- 학생은 ⌄ 로 대화창을 내려 두고 공부하면서 답장을 기다릴 수 있어요.
- **선생님이 독서실을 켜 두지 않아도 돼요**: 이메일을 등록하면 교무실에 없을 때 질문이 오면 메일로 알려요(내용은 안 넣음, 같은 대화 10분에 한 번). 메일 링크를 누르면 바로 독서실로.
- **🔒 문 닫기**: 선생님 부르기 목록에서 '📝 시험 출제 중'으로 보이고 새 질문을 받지 않아요(하던 대화는 계속). 다시 받으려면 **🔓 문 열기**.
- **관리자**만 학생을 **차단**할 수 있어요 (`차단` 탭에 기기 번호만 남음). 일반 선생님은 학생 구경·대화·질문 받기·학생 부르기·내 문 열고 닫기만 해요.
- 일반 선생님은 대화창의 **🚨 관리자에게**로 학생을 알려요 → `신고` 탭에 학생의 최근 메시지(5개까지)가 남고 관리자에게 메일. 관리자는 [📥 받은 대화 → 🛠️ 관리자 메뉴]에서 **신고 처리(차단/넘어가기) · 차단 풀기 · 초대코드 만들기 · 선생님 끄기/켜기 · 모든 기기 로그아웃 · 비밀번호 초기화**를 해요.

### 교무실 설치 (선생님이 한 번만)
1. 같은 Apps Script 프로젝트에 파일 추가(+) → 스크립트 → 이름 `Office` → [`apps-script/Office.gs`](apps-script/Office.gs) 내용 붙여 넣기. `Code.gs`도 최신으로 바꾸기.
2. 편집기에서 `setupOffice` 실행 → `교사`·`차단` 탭이 생기고 초대코드 3개가 만들어져요 (메일 권한 승인).
3. **배포 → 배포 관리 → 연필 → 새 버전 → 배포** (주소는 그대로).
4. 선생님들께 초대코드를 한 명에 하나씩 알려 주세요. 독서실 ⚙️ 설정(또는 교무실 안) → **👩‍🏫 선생님 로그인 → 처음 등록**에서 초대코드·닉네임·비밀번호·이메일과 입력.
   다음부터는 **초대코드 + 닉네임 + 비밀번호**로 로그인하고, 한 번 로그인한 기기는 로그아웃할 때까지 계속 로그인돼 있어요.
5. 초대코드가 더 필요하면 시트 메뉴 **🐾 독서실 → 교사 초대코드 만들기**. 권한을 빼려면 `교사` 탭의 '사용' 체크 해제.

## Firebase 보안 규칙
Realtime Database → 규칙에 그대로 넣어요. 학생은 자기 정보만 쓸 수 있고, 남이 앉은 자리는 빼앗을 수 없어요.
```json
{"rules":{"rooms":{"$room":{"players":{".read":"auth != null","$uid":{".write":"auth != null && auth.uid === $uid",".validate":"!newData.exists() || (newData.child('n').isString() && newData.child('n').val().length <= 12)"}},"seats":{".read":"auth != null","$seat":{".write":"auth != null && ((!data.exists() && newData.val() === auth.uid) || (data.exists() && data.val() === auth.uid && !newData.exists()) || (data.exists() && !root.child('rooms').child($room).child('players').child(data.val()).exists() && newData.val() === auth.uid))"}},"calls":{"$uid":{".read":"auth != null && auth.uid === $uid",".write":"auth != null","$id":{".validate":"!newData.exists() || (newData.child('conv').isString() && newData.child('key').isString())"}}},"fx":{".read":"auth != null","$id":{".write":"auth != null",".validate":"!newData.exists() || (newData.child('e').isString() && newData.child('e').val().length <= 4 && newData.child('to').isString())"}}}}}}
```
